1. Send the conversation to the model, along with the list of tools.
2. The model replies. Its reply either **is** the answer, or it is a request.
3. If it is a request: run the tool, paste the result back, and go to step 1.

## Callouts

<Callout type="lesson">
  The description is the **only** thing the model reads when deciding whether
  to use your tool. Vague description, and your tool never gets called.
</Callout>

<Callout type="gotcha" title="create-next-app refuses to share a folder">
  It will not scaffold into a directory containing any unrecognised file.
  Scaffold to a temp dir and copy in.
</Callout>

<Callout type="warning">
  Cost is superlinear in iterations, because each trip resends everything
  before it. A five-step task does not cost five times a one-step task.
</Callout>

<Callout type="insight">
  `input_tokens` is only the *uncached remainder*. The real prompt size is
  `input + cache_creation + cache_read`.
</Callout>

## Code

```ts title="lib/approval.ts" {6-9}
export function classifyCall(toolName: string, args: unknown): GateVerdict {
  const safeArgs: Record<string, unknown> =
    args && typeof args === "object" && !Array.isArray(args)
      ? (args as Record<string, unknown>)
      : {};

  for (const rule of RULES) {
    if (rule.tool !== toolName) continue;
    if (rule.matches(safeArgs)) return { decision: "ask", reason: rule.reason };
  }

  return { decision: DEFAULT_DECISION };
}
```

## A table

| Seatbelt | Kind of limit | What it catches that the others don't |
|---|---|---|
| `MAX_ITERATIONS = 10` | per agent | One agent spinning. |
| `MAX_CONCURRENT = 3` | rate | Three-wide is a bill times three, not times sixty. |
| `MAX_SPAWNS = 8` | quantity | An orchestrator hiring sixty workers, politely, three at a time. |
| `MAX_TREE_TOKENS` | money | The only check that sees the whole bill. |
